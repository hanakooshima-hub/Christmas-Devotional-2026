# Christmas Devotional 2026

A bilingual Japanese-English devotional journey for November 12–December 25, 2026.

## Files
- `index.html` — page structure
- `style.css` — sage green, warm ivory and gold design
- `script.js` — navigation, language switch, progress and private journal
- `devotions.json` — 44 daily readings, reflections and prayers

## Publish with GitHub Pages
1. Open **Settings** in this repository.
2. Select **Pages** in the left sidebar.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch **main** and folder **/(root)**, then Save.
5. Wait a few minutes. The site should appear at:
   https://hanakooshima-hub.github.io/Christmas-Devotional-2026/

## Privacy
Journal notes and completion status are stored in the browser's local storage on the device being used. They are not sent to GitHub. Clearing browser data or changing devices may remove or hide those notes.

Bible passages are given as references. Please read them in your preferred Bible translation.
